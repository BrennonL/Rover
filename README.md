# Rover
A project utilizing an Ardiuno Super Learning Kit, PlatformIO, and C++ to build a small autonomous rover. This will use watchdog and I plan to incorporate an MCU pipeline

# Dependencies
- PlatformIO (on VS code)
- Linux

# How to Use

Ensure your Arduino R3 is connected to the computer. Then run the command in `./`:

```bash
pio run
```

If it runs with no errors then you can push the code to the arduino with:
```bash
pio run -t upload
```
